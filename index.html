Project typeAcademic data engineering project
SkillsApache Spark, Kafka, MySQL, Python, Machine Learning

Overview / Description

Four typed Kafka streams feed Spark batch pipelines that clean, join, and aggregate epidemic data before storing analytical outputs in MySQL.

Objective / Success Metrics

Create a dependable end-to-end workflow that can surface geographic anomalies and support outbreak prediction from multiple live-style data sources.

Approach

  • Stored structured results in MySQL and layered anomaly detection and predictive modeling on top.

Legal Data Analytics

Medical Case Analytics

A text-processing workflow that turns unstructured Massachusetts court filings into traceable medical-debt insights.

Project typeApplied legal analytics project
SkillsPython, Regex, Fuzzy Matching, EDA, Data Visualization
10 yearscourt filings→structured cases

Overview / Description

The project extracts medical case signals from a decade of court filings, standardizes noisy creditor names, and organizes cases into analysis-ready categories.

Objective / Success Metrics

Reduce manual review, improve matching consistency, and reveal which creditors and case types drive the largest share of activity.

Approach

  • Created regex rules to detect medical and debt-related language.
  • Applied fuzzy matching to consolidate spelling variations and duplicated entities.
  • Used exploratory analysis to identify concentrated creditor behavior and long-term patterns.

SkillsXGBoost, MLP, PCA, GMM, Model Evaluation

Quantitative Finance

Portfolio Optimization

A forecasting and asset-allocation workflow that connects LSTM return estimates with Black–Litterman portfolio construction.

Project typeQuantitative finance project
SkillsR, LSTM, Black–Litterman, Portfolio Analytics
100 ETFs→Top 20by Sharpe ratio

Overview / Description

The project forecasts asset behavior with an LSTM model, then uses those views within a Black–Litterman framework to build a diversified portfolio.

Objective / Success Metrics

Improve risk-adjusted performance against a broad benchmark set; the resulting strategy outperformed 70% of 100 benchmark ETFs.

Approach

  • Screened 100 ETFs and prepared historical return features.
  • Generated forward-looking views with an LSTM forecasting model.
  • Combined model views with Black–Litterman optimization and ranked outcomes by Sharpe ratio.
